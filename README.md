## Skills
Copy the skill into your project and trigger it based on your agent skill docs:
e.g.
Assuming the project you want to analyze is called `my-project`
- 1. ` cp -r B.O.A.T/.opencode/skills/code-explorer my-project `
- 2. Inside opencode run: /skills/code-explorer
